# VAZ Scan — диагностика через ELM327 (Android)

Профессиональное приложение для диагностики ВАЗ 2112 (1.5, 8 кл.) через Bluetooth-адаптер ELM327.
Архитектура рассчитана на замену адаптера: весь обмен идёт через интерфейс `ObdTransport`
(сейчас Bluetooth и демо-режим; позже можно добавить USB / Wi-Fi / BLE для оригинального сканера).

## Возможности
- Автоподключение: инициализация ELM327, автопоиск протокола, запасной перебор K-line (ISO 9141 / KWP).
- Полная диагностика одной кнопкой: связь, напряжение, поддерживаемые датчики, лампа Check Engine,
  готовность систем, сохранённые / ожидающие / постоянные ошибки, стоп-кадр, живые данные, анализ лямбда-зонда.
- Анализ: топливные коррекции, температура ОЖ, напряжение бортсети, холостой ход, ДМРВ, дроссель, лямбда-зонд.
- Оценка состояния 0-100 и список выводов с рекомендациями.
- База ошибок на русском: описание, возможные причины по вероятности, что проверять и в каком порядке.
- Датчики в реальном времени с мини-графиками.
- Чтение и сброс ошибок (перед сбросом ошибки сохраняются в историю).
- История отчётов, экспорт отчёта текстом (мессенджер, почта).
- Терминал для ручных AT/OBD-команд.
- Демо-режим без автомобиля.

## Как получить APK (через GitHub)
1. Создайте репозиторий и загрузите содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions**, запустите **Build APK** (или он запустится сам после загрузки).
3. После сборки скачайте артефакт **VazScan-debug-apk**, распакуйте и установите `app-debug.apk`
   (разрешите установку из неизвестных источников).

Либо откройте папку в Android Studio и нажмите Run.

## Подключение
1. Вставьте адаптер в OBD-разъём, включите зажигание.
2. Сопрягите адаптер в настройках Bluetooth телефона (пароль 1234 или 0000).
3. Приложение → «Подключение» → выберите адаптер.

## Ограничения
- ELM327 читает стандартный OBD-II: двигатель и выхлоп. ABS, подушки, приборную панель не читает.
- Старые блоки ВАЗ (Январь 5.1 / 7.2 и др.) могут поддерживать OBD-II частично или нет. Для них нужен родной протокол.
- Дешёвые клоны ELM327 могут быть нестабильны.
